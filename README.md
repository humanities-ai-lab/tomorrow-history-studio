# 明日歷史工作室 (Tomorrow's History Studio)

這是明日歷史工作室的官方招募網頁。

## 如何部署到 GitHub Pages

1. 在 GitHub 上創建一個新的 Repository，名稱可以叫 `tomorrow-history-studio`。
2. 在本地終端機執行以下指令：

```bash
cd tomorrow-history-studio
git init
git add .
git commit -m "Initial commit"
git branch -M main
git remote add origin https://github.com/你的帳號/tomorrow-history-studio.git
git push -u origin main
```

3. 到 GitHub Repository 的 **Settings > Pages**。
4. 在 **Build and deployment > Branch** 選擇 `main` 分支並儲存。
5. 稍等幾分鐘，你的網站就會在 `https://你的帳號.github.io/tomorrow-history-studio/` 上線了！
